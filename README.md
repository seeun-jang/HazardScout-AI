# HazardScout-AI

## 상황추론 기반 위험환경 자율 탐사·점검 로봇 시스템

**HazardScout-AI**는 사람이 직접 접근하기 어렵거나 위험한 환경에서  
로봇 시스템을 활용하여 현장을 탐사·점검하고, 수집된 정보를 기반으로  
상황을 판단하여 필요한 동작을 수행하는 것을 목표로 하는 프로젝트입니다.

로봇 주행 및 로봇팔 제어를 기반으로 환경 인식, 상황 판단,  
AI 기반 명령 처리 및 관제 기능을 단계적으로 구현하여  
최종적으로 하나의 통합형 위험환경 대응 시스템을 구축하는 것을 목표로 합니다.

## Project Objectives

- 위험 환경에서의 로봇 자율 주행 및 탐사
- 센서 및 카메라 기반 환경 정보 수집
- 로봇팔을 활용한 위험요소 점검 및 조치
- AI 기반 자연어·음성 명령 처리
- 상황 정보를 기반으로 한 판단 및 조치 로직 구현
- 관제 대시보드를 통한 로봇 상태 및 작업 로그 관리
- 각 기능을 연동한 통합 위험환경 대응 시스템 구축

## Development Status

현재 **로봇 이동 제어 기능**을 우선적으로 개발하고 있습니다.

실제 로봇에서 기본 주행 기능을 구현 및 테스트하고 있으며,  
이후 프로젝트 일정에 따라 센서, 로봇팔 제어, AI 명령 처리,  
상황판단 및 관제 기능을 단계적으로 통합할 예정입니다.
