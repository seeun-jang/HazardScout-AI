# HazardScout-AI

## 상황추론 기반 위험환경 자율 탐사·점검 로봇 시스템

**HazardScout-AI**는 사람이 직접 접근하기 어렵거나 위험한 환경에서  
로봇 시스템을 활용하여 현장을 탐사·점검하고, 수집된 정보를 기반으로  
상황을 판단하여 필요한 동작을 수행하는 것을 목표로 하는 프로젝트입니다.

본 프로젝트는 로봇 이동 및 로봇팔 제어를 기반으로  
환경 인식, 위험 상황 판단, 상황추론 기능을 단계적으로 구현하고  
최종적으로 각 기능을 하나의 통합 시스템으로 구성하는 것을 목표로 합니다.

---

## Project Objectives

- 위험 환경에서의 로봇 이동 및 탐사
- 로봇팔을 활용한 점검 및 대응 동작
- 카메라 및 센서 기반 환경 정보 수집
- AI 기반 위험 상황 인식 및 상황추론
- 로봇 상태 및 탐사 결과 모니터링

---
