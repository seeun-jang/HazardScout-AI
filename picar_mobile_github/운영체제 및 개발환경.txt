3. I2C / PWM / OLED 최종 설정 (신규 반영)
----------------------------------------------------------------------
항목                          값 / 설명
I2C 버스                     1 (/dev/i2c-1)
OLED 종류                    SSD1306
OLED 주소                    0x3C
서보 드라이버                 PCA9685
PCA9685 주소                 0x5F
PWM 주파수                   50Hz
I2C 부팅 속도                400000 baud (400kHz)
설정 파일                    /boot/firmware/config.txt
적용 항목                    dtparam=i2c_arm=on,i2c_arm_baudrate=400000
설정 변경 전 백업            /boot/firmware/config.txt.before_i2c400k
OLED 전체 화면 전송 전       평균 94.63ms (기존 설정)
OLED 전체 화면 전송 후       평균 24.80ms (400kHz)
성능 차이                    약 73.8% 감소, 약 3.8배 빠름

[서보 채널]
채널 0 : 앞바퀴 조향 (기존 PWM 출력 방식)
채널 1 : 목 A 좌우 (PWM 객체 재사용)
채널 2 : 목 B 상하 (PWM 객체 재사용)
채널 3 : 목 A 상하 (PWM 객체 재사용)
채널 4 : 집게 (기존 PWM 출력 방식)

[최종 목 움직임]
A 좌우(a_pan) : 초기 기준 위치에서 -25° ~ +25°, 조작 방향 반전 보정
A 상하(a_tilt): 초기 기준 위치에서 -12° ~ +12°, 기존 설정 유지
B 상하(b_tilt): 초기 기준 위치에서 -20° ~ +12°, 아래로만 추가 확장

[목/OLED 제어]
- 목 1/2/3번 PCA9685 객체 재사용으로 제어 객체 생성 비용 감소.
- 목 서보는 기존 단계별 이동 주기(약 55ms)를 유지.
- OLED 화면 체크 간격 약 80ms.
- 변경된 화면만 실제 OLED 전송, 중복 화면 생략.
- 목·집게를 조작하는 동안 OLED 갱신을 보류함.
- 서보 정지 후 약 0.2초부터 OLED 갱신 재개.
- 눈동자 방향/깜빡임 유지, 미세 애니메이션 전송은 약 0.5초 예산.
